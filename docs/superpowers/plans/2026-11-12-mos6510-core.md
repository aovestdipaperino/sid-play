# mos6510 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `mos6510`, a cycle-exact, permissively licensed MOS 6510/6502 core, verify it against Harte's SingleStepTests and Klaus Dormann's functional test, and replace `lib6502` in rust-sid's PSID harness with it.

**Architecture:** One `tick()` per Φ2 cycle, one bus access per tick. Instructions are decoded through a 256-entry table into (operation, addressing mode); a small set of addressing-mode cycle sequences performs the bus accesses, and pure ALU functions in `ops.rs` compute results. Branches, stack instructions, `JSR`/`RTS`/`RTI`, `JMP`, `BRK`/IRQ/NMI/reset and JAM have their own sequences. Interrupts are latched by a poll at the end of every non-final cycle, so the last poll before an instruction ends is the one that counts, with the branch exceptions the hardware has.

**Tech Stack:** Rust 2024 edition, no runtime dependencies, `serde_json` as a dev-dependency for the Harte runner, POSIX `sh` + `curl` for test-data fetch scripts.

Spec: `docs/superpowers/specs/2026-11-12-mos6510-core-design.md`.

`README.md`:

````markdown
# mos6510

A cycle-exact MOS 6510 / 6502 CPU core in Rust.

- `Cpu::tick` runs one Φ2 cycle and performs exactly one bus access, dummy
  reads and writes included.
- All 256 opcodes, including every undocumented one. The unstable `ANE`/`LXA`
  use the magic constant `UNSTABLE_MAGIC` (`$EE`).
- Interrupts are sampled where the NMOS part samples them: IRQ is
  level-triggered, NMI edge-triggered, an NMI can hijack `BRK`/IRQ.
- The 6510's I/O port at `$00`/`$01` (`Model::Mos6510`), or none
  (`Model::Mos6502`).
- No dependencies, no `unsafe`.

```rust
use mos6510::{Bus, Cpu, Model};

struct Ram(Vec<u8>);
impl Bus for Ram {
    fn read(&mut self, addr: u16) -> u8 { self.0[usize::from(addr)] }
    fn write(&mut self, addr: u16, value: u8) { self.0[usize::from(addr)] = value; }
}

let mut ram = Ram(vec![0; 0x1_0000]);
let mut cpu = Cpu::new(Model::Mos6510); // runs the reset sequence first
for _ in 0..1000 {
    cpu.tick(&mut ram);
}
```
````

```rust
//! Arithmetic and logic on register values.
//!
//! Nothing here touches the bus, so each operation can be checked on its own.
//! Every function takes the status register by `&mut` and returns the result.

pub(crate) const C: u8 = 0x01;
pub(crate) const Z: u8 = 0x02;
pub(crate) const I: u8 = 0x04;
pub(crate) const D: u8 = 0x08;
pub(crate) const B: u8 = 0x10;
pub(crate) const U: u8 = 0x20;
pub(crate) const V: u8 = 0x40;
pub(crate) const N: u8 = 0x80;

/// The constant `ANE` (`$8B`) and `LXA` (`$AB`) OR into A before masking.
///
/// On real NMOS parts this value varies from chip to chip and with
/// temperature. `$EE` is what Tom Harte's SingleStepTests record and the most
/// commonly observed value.
pub const UNSTABLE_MAGIC: u8 = 0xEE;

pub(crate) fn set(p: &mut u8, flag: u8, on: bool) {
    if on {
        *p |= flag;
    } else {
        *p &= !flag;
    }
}

pub(crate) fn set_nz(p: &mut u8, v: u8) {
    set(p, Z, v == 0);
    set(p, N, v & 0x80 != 0);
}

/// Add with carry. In NMOS decimal mode Z comes from the binary sum, N and V
/// from the result after the low-nibble adjust, C from the final adjust.
pub(crate) fn adc(p: &mut u8, a: u8, m: u8) -> u8 {
    let c = u16::from(*p & C);
    let bin = u16::from(a) + u16::from(m) + c;
    if *p & D == 0 {
        let r = bin as u8;
        set(p, C, bin > 0xff);
        set(p, V, !(a ^ m) & (a ^ r) & 0x80 != 0);
        set_nz(p, r);
        return r;
    }
    let mut lo = u16::from(a & 0x0f) + u16::from(m & 0x0f) + c;
    if lo > 0x09 {
        lo += 0x06;
    }
    let mut hi = u16::from(a >> 4) + u16::from(m >> 4) + u16::from(lo > 0x0f);
    set(p, Z, bin & 0xff == 0);
    let half = ((hi << 4) | (lo & 0x0f)) as u8;
    set(p, N, half & 0x80 != 0);
    set(p, V, !(a ^ m) & (a ^ half) & 0x80 != 0);
    if hi > 0x09 {
        hi += 0x06;
    }
    set(p, C, hi > 0x0f);
    ((hi << 4) | (lo & 0x0f)) as u8
}

/// Subtract with borrow (borrow = !C). On NMOS every flag comes from the
/// binary result, in decimal mode too; only A is decimal-adjusted.
pub(crate) fn sbc(p: &mut u8, a: u8, m: u8) -> u8 {
    let borrow = i16::from(*p & C == 0);
    let bin = i16::from(a) - i16::from(m) - borrow;
    let r = bin as u8;
    set(p, C, bin >= 0);
    set(p, V, (a ^ m) & (a ^ r) & 0x80 != 0);
    set_nz(p, r);
    if *p & D == 0 {
        return r;
    }
    let mut lo = i16::from(a & 0x0f) - i16::from(m & 0x0f) - borrow;
    let mut hi = i16::from(a >> 4) - i16::from(m >> 4);
    if lo < 0 {
        lo -= 0x06;
        hi -= 1;
    }
    if hi < 0 {
        hi -= 0x06;
    }
    ((hi << 4) | (lo & 0x0f)) as u8
}

/// `CMP`/`CPX`/`CPY`: C is "no borrow", N and Z from the difference.
pub(crate) fn compare(p: &mut u8, r: u8, m: u8) {
    set(p, C, r >= m);
    set_nz(p, r.wrapping_sub(m));
}

pub(crate) fn bit(p: &mut u8, a: u8, m: u8) {
    set(p, Z, a & m == 0);
    set(p, N, m & 0x80 != 0);
    set(p, V, m & 0x40 != 0);
}

pub(crate) fn asl(p: &mut u8, v: u8) -> u8 {
    set(p, C, v & 0x80 != 0);
    let r = v << 1;
    set_nz(p, r);
    r
}

pub(crate) fn lsr(p: &mut u8, v: u8) -> u8 {
    set(p, C, v & 0x01 != 0);
    let r = v >> 1;
    set_nz(p, r);
    r
}

pub(crate) fn rol(p: &mut u8, v: u8) -> u8 {
    let r = (v << 1) | (*p & C);
    set(p, C, v & 0x80 != 0);
    set_nz(p, r);
    r
}

pub(crate) fn ror(p: &mut u8, v: u8) -> u8 {
    let r = (v >> 1) | ((*p & C) << 7);
    set(p, C, v & 0x01 != 0);
    set_nz(p, r);
    r
}

/// `ANC`: AND, then C copies N.
pub(crate) fn anc(p: &mut u8, a: u8, m: u8) -> u8 {
    let r = a & m;
    set_nz(p, r);
    set(p, C, r & 0x80 != 0);
    r
}

/// `ALR`: AND, then LSR.
pub(crate) fn alr(p: &mut u8, a: u8, m: u8) -> u8 {
    lsr(p, a & m)
}

/// `ARR`: AND, then ROR, with its own flag rules and an NMOS decimal variant.
pub(crate) fn arr(p: &mut u8, a: u8, m: u8) -> u8 {
    let t = a & m;
    let carry = *p & C;
    let mut r = (t >> 1) | (carry << 7);
    if *p & D == 0 {
        set_nz(p, r);
        set(p, C, r & 0x40 != 0);
        set(p, V, ((r >> 6) ^ (r >> 5)) & 1 != 0);
        return r;
    }
    set(p, N, carry != 0);
    set(p, Z, r == 0);
    set(p, V, (t ^ r) & 0x40 != 0);
    let (hi, lo) = (t >> 4, t & 0x0f);
    if lo + (lo & 1) > 5 {
        r = (r & 0xf0) | (r.wrapping_add(6) & 0x0f);
    }
    let c = hi + (hi & 1) > 5;
    set(p, C, c);
    if c {
        r = r.wrapping_add(0x60);
    }
    r
}

/// `SBX` (also called AXS): X = (A & X) - imm, flags like CMP, no decimal.
pub(crate) fn sbx(p: &mut u8, a: u8, x: u8, m: u8) -> u8 {
    let t = a & x;
    set(p, C, t >= m);
    let r = t.wrapping_sub(m);
    set_nz(p, r);
    r
}

/// `ANE` (also called XAA): A = (A | magic) & X & imm.
pub(crate) fn ane(p: &mut u8, a: u8, x: u8, m: u8) -> u8 {
    let r = (a | UNSTABLE_MAGIC) & x & m;
    set_nz(p, r);
    r
}

/// `LXA`: A = X = (A | magic) & imm.
pub(crate) fn lxa(p: &mut u8, a: u8, m: u8) -> u8 {
    let r = (a | UNSTABLE_MAGIC) & m;
    set_nz(p, r);
    r
}
```

```rust
//! Tom Harte's SingleStepTests for the NMOS 6502 (MIT licence), compared cycle
//! by cycle: every bus access's address, value and direction, then the final
//! registers and memory.
//!
//! The data (~1.3 GB) is not in the repository. Fetch it with
//! `sh scripts/fetch-harte.sh` and run with `HARTE_DIR=target/test-data/harte`.
//! Without it the test is skipped. `HARTE_OPS=69,6b` limits the run.

use mos6510::{Bus, Cpu, Model};
use serde_json::Value;
use std::path::PathBuf;

/// Flat RAM that logs every access as (address, value, is_write).
struct TestBus {
    mem: Vec<u8>,
    log: Vec<(u16, u8, bool)>,
}

impl Bus for TestBus {
    fn read(&mut self, addr: u16) -> u8 {
        let v = self.mem[usize::from(addr)];
        self.log.push((addr, v, false));
        v
    }

    fn write(&mut self, addr: u16, value: u8) {
        self.mem[usize::from(addr)] = value;
        self.log.push((addr, value, true));
    }
}

fn num(v: &Value) -> u64 {
    v.as_u64().expect("a number in the test data")
}

fn byte(v: &Value) -> u8 {
    u8::try_from(num(v)).expect("a byte")
}

fn word(v: &Value) -> u16 {
    u16::try_from(num(v)).expect("a 16-bit value")
}

fn run_case(case: &Value, bus: &mut TestBus) -> Result<(), String> {
    let init = &case["initial"];
    let fin = &case["final"];
    let ram_init = init["ram"].as_array().expect("initial ram");
    let ram_final = fin["ram"].as_array().expect("final ram");
    for e in ram_init {
        bus.mem[usize::from(word(&e[0]))] = byte(&e[1]);
    }
    bus.log.clear();

    let mut cpu = Cpu::new(Model::Mos6502);
    cpu.a = byte(&init["a"]);
    cpu.x = byte(&init["x"]);
    cpu.y = byte(&init["y"]);
    cpu.s = byte(&init["s"]);
    cpu.p = byte(&init["p"]);
    cpu.jump(word(&init["pc"]));

    let cycles = case["cycles"].as_array().expect("cycles");
    for _ in 0..cycles.len() {
        cpu.tick(bus);
    }

    let mut result = Ok(());
    for (i, want) in cycles.iter().enumerate() {
        let want = (word(&want[0]), byte(&want[1]), want[2].as_str() == Some("write"));
        let got = bus.log.get(i).copied();
        if got != Some(want) {
            result = Err(format!("cycle {i}: got {got:?}, want {want:?} (addr, value, write)"));
            break;
        }
    }
    if result.is_ok() && bus.log.len() != cycles.len() {
        result = Err(format!("{} bus accesses, want {}", bus.log.len(), cycles.len()));
    }
    if result.is_ok() {
        let regs = [
            ("pc", u64::from(cpu.pc), num(&fin["pc"])),
            ("s", u64::from(cpu.s), num(&fin["s"])),
            ("a", u64::from(cpu.a), num(&fin["a"])),
            ("x", u64::from(cpu.x), num(&fin["x"])),
            ("y", u64::from(cpu.y), num(&fin["y"])),
            ("p", u64::from(cpu.p), num(&fin["p"])),
        ];
        for (name, got, want) in regs {
            if got != want {
                result = Err(format!("{name}: got {got:#x}, want {want:#x}"));
                break;
            }
        }
    }
    if result.is_ok() {
        for e in ram_final {
            let (addr, want) = (word(&e[0]), byte(&e[1]));
            let got = bus.mem[usize::from(addr)];
            if got != want {
                result = Err(format!("ram[{addr:#06x}]: got {got:#04x}, want {want:#04x}"));
                break;
            }
        }
    }

    // Leave the memory all zeros for the next case without clearing 64 KiB.
    for e in ram_init.iter().chain(ram_final) {
        bus.mem[usize::from(word(&e[0]))] = 0;
    }
    for &(addr, _, _) in &bus.log {
        bus.mem[usize::from(addr)] = 0;
    }
    result
}
```

```rust
//! The 6510's on-chip I/O port: a data direction register at `$00` and a
//! data register at `$01`. A set direction bit makes the pin an output.

#[derive(Clone, Copy, Debug)]
pub(crate) struct Port {
    pub(crate) ddr: u8,
    pub(crate) data: u8,
    /// What external circuitry pulls each pin to.
    pub(crate) pins: u8,
}

impl Port {
    /// Power-on: every pin an input, the data register clear, pins pulled high.
    pub(crate) const fn new() -> Self {
        Self {
            ddr: 0,
            data: 0,
            pins: 0xff,
        }
    }

    /// The level on each pin: outputs from the data register, inputs from
    /// outside.
    pub(crate) const fn levels(&self) -> u8 {
        (self.data & self.ddr) | (self.pins & !self.ddr)
    }

    pub(crate) const fn read(&self, addr: u16) -> u8 {
        if addr == 0 { self.ddr } else { self.levels() }
    }

    pub(crate) fn write(&mut self, addr: u16, value: u8) {
        if addr == 0 {
            self.ddr = value;
        } else {
            self.data = value;
        }
    }
}
```

```rust
//! A cycle-exact MOS 6510 / 6502 CPU core.
//!
//! [`Cpu::tick`] advances exactly one Φ2 cycle and performs exactly one bus
//! access, dummy reads and writes included, so a host can run the processor
//! in lockstep with other chips. All 256 opcodes are implemented, including
//! every undocumented one, and interrupts are sampled where the NMOS part
//! samples them.

#![forbid(unsafe_code)]
#![warn(missing_docs)]

mod decode;
mod ops;
mod port;

use decode::{Kind, Mode, Op, TABLE};
use ops::{B, C, D, I, N, U, V, Z};
pub use ops::UNSTABLE_MAGIC;
use port::Port;

const STACK: u16 = 0x0100;
const NMI_VECTOR: u16 = 0xfffa;
const RESET_VECTOR: u16 = 0xfffc;
const IRQ_VECTOR: u16 = 0xfffe;

/// Memory and I/O as the processor sees them.
pub trait Bus {
    /// Read a byte. Takes `&mut self` because reads have side effects on real
    /// hardware: a CIA clears its interrupt flags when they are read.
    fn read(&mut self, addr: u16) -> u8;
    /// Write a byte.
    fn write(&mut self, addr: u16, value: u8);
}

/// Which part to emulate.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Model {
    /// The C64's processor: a 6502 with an I/O port at `$00`/`$01`.
    Mos6510,
    /// A plain NMOS 6502, where `$00`/`$01` are ordinary bus addresses.
    Mos6502,
}

/// Why the BRK-shaped sequence is running.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum Entry {
    Brk,
    Interrupt,
    Reset,
}

/// The processor. The registers are public so a host can set up a call.
#[derive(Clone, Debug)]
pub struct Cpu {
    /// Accumulator.
    pub a: u8,
    /// X index register.
    pub x: u8,
    /// Y index register.
    pub y: u8,
    /// Stack pointer, an offset into page 1.
    pub s: u8,
    /// Status, `NV-BDIZC`. Bit 5 stays set; only `PLP` and `RTI` clear B.
    pub p: u8,
    /// Program counter.
    pub pc: u16,
    model: Model,
    port: Port,
    op: Op,
    mode: Mode,
    /// Cycle within the current sequence; 0 means the next tick fetches.
    t: u8,
    addr: u16,
    base: u16,
    ptr: u8,
    data: u8,
    entry: Entry,
    reset_pending: bool,
    jammed: bool,
    irq_line: bool,
    nmi_line: bool,
    nmi_edge: bool,
    /// The result of the last interrupt poll: whether the next boundary
    /// starts an interrupt sequence.
    take_int: bool,
    skip_poll: bool,
}

impl Cpu {
    /// A processor at power-on. Its first seven ticks run the reset sequence,
    /// which loads PC from `$FFFC`.
    pub fn new(model: Model) -> Self {
        let mut cpu = Self {
            a: 0,
            x: 0,
            y: 0,
            s: 0,
            p: U | I,
            pc: 0,
            model,
            port: Port::new(),
            op: Op::Nop,
            mode: Mode::Imp,
            t: 0,
            addr: 0,
            base: 0,
            ptr: 0,
            data: 0,
            entry: Entry::Reset,
            reset_pending: false,
            jammed: false,
            irq_line: false,
            nmi_line: false,
            nmi_edge: false,
            take_int: false,
            skip_poll: false,
        };
        cpu.reset();
        cpu
    }

    /// Run the 7-cycle reset sequence from the next tick: three stack reads
    /// that decrement S, then PC from `$FFFC`, with I set.
    pub fn reset(&mut self) {
        self.reset_pending = true;
        self.jammed = false;
        self.take_int = false;
        self.t = 0;
    }

    /// Start executing at `pc` on the next tick, abandoning any instruction in
    /// progress and any pending reset. For hosts that call routines directly.
    pub fn jump(&mut self, pc: u16) {
        self.pc = pc;
        self.t = 0;
        self.reset_pending = false;
        self.jammed = false;
        self.take_int = false;
    }

    /// Drive the IRQ line. Level-triggered: hold it while the source asserts.
    pub fn set_irq(&mut self, asserted: bool) {
        self.irq_line = asserted;
    }

    /// Drive the NMI line. Edge-triggered: an interrupt is requested when it
    /// goes from released to asserted.
    pub fn set_nmi(&mut self, asserted: bool) {
        if asserted && !self.nmi_line {
            self.nmi_edge = true;
        }
        self.nmi_line = asserted;
    }

    /// The next tick starts a new instruction (or an interrupt sequence).
    pub fn at_instruction_boundary(&self) -> bool {
        self.t == 0 && !self.jammed
    }

    /// At a boundary, the next tick begins an interrupt sequence rather than
    /// an opcode fetch.
    pub fn interrupt_pending(&self) -> bool {
        self.at_instruction_boundary() && !self.reset_pending && self.take_int
    }

    /// A JAM opcode ran. Only [`Cpu::reset`] or [`Cpu::jump`] recovers.
    pub fn jammed(&self) -> bool {
        self.jammed
    }

    /// The I/O port's pin levels (`Model::Mos6510`): outputs as written to
    /// `$01`, inputs as set by [`Cpu::set_port_input`].
    pub fn port_output(&self) -> u8 {
        self.port.levels()
    }

    /// What external circuitry pulls the port pins to. Default: all high.
    pub fn set_port_input(&mut self, pins: u8) {
        self.port.pins = pins;
    }

    /// Load the port's direction (`$00`) and data (`$01`) registers directly,
    /// for a host that starts a program without running the code that would
    /// set them.
    pub fn set_port_registers(&mut self, ddr: u8, data: u8) {
        self.port.ddr = ddr;
        self.port.data = data;
    }

    /// Run one Φ2 cycle: exactly one bus access.
    pub fn tick(&mut self, bus: &mut impl Bus) {
        self.skip_poll = false;
        let done = if self.t == 0 {
            self.begin(bus);
            false
        } else {
            self.step(bus)
        };
        if done {
            self.t = 0;
        } else {
            self.t = self.t.saturating_add(1);
            // Polling at the end of every cycle but the last means the poll
            // that decides is the one in the penultimate cycle.
            if !self.skip_poll {
                self.poll();
            }
        }
    }

    fn poll(&mut self) {
        self.take_int = self.nmi_edge || (self.irq_line && self.p & I == 0);
    }

    fn read(&self, bus: &mut impl Bus, addr: u16) -> u8 {
        let value = bus.read(addr);
        if self.model == Model::Mos6510 && addr < 2 {
            self.port.read(addr)
        } else {
            value
        }
    }

    fn write(&mut self, bus: &mut impl Bus, addr: u16, value: u8) {
        if self.model == Model::Mos6510 && addr < 2 {
            self.port.write(addr, value);
        }
        // The write reaches the bus too, so the RAM under the port sees it.
        bus.write(addr, value);
    }

    fn operand(&mut self, bus: &mut impl Bus) -> u8 {
        let v = self.read(bus, self.pc);
        self.pc = self.pc.wrapping_add(1);
        v
    }

    fn stack_push(&mut self, bus: &mut impl Bus, value: u8) {
        self.write(bus, STACK | u16::from(self.s), value);
        self.s = self.s.wrapping_sub(1);
    }

    /// Cycle 0: an opcode fetch, or the dummy fetch that starts an interrupt
    /// or reset sequence.
    fn begin(&mut self, bus: &mut impl Bus) {
        if self.reset_pending || self.take_int {
            self.read(bus, self.pc);
            self.entry = if self.reset_pending {
                Entry::Reset
            } else {
                Entry::Interrupt
            };
            self.reset_pending = false;
            self.take_int = false;
            self.op = Op::Brk;
            self.mode = Mode::Imp;
            self.skip_poll = true;
            return;
        }
        let opcode = self.operand(bus);
        let (op, mode) = TABLE[usize::from(opcode)];
        self.op = op;
        self.mode = mode;
        self.entry = Entry::Brk;
    }

    /// Cycles 1 and later. Returns true on the instruction's last cycle.
    fn step(&mut self, bus: &mut impl Bus) -> bool {
        match self.op {
            Op::Brk => self.brk(bus),
            Op::Jsr => self.jsr(bus),
            Op::Rts => self.rts(bus),
            Op::Rti => self.rti(bus),
            Op::Jmp => self.jmp(bus),
            Op::JmpInd => self.jmp_ind(bus),
            Op::Pha | Op::Php => self.push_op(bus),
            Op::Pla | Op::Plp => self.pull_op(bus),
            Op::Jam => self.jam(bus),
            Op::Bpl
            | Op::Bmi
            | Op::Bvc
            | Op::Bvs
            | Op::Bcc
            | Op::Bcs
            | Op::Bne
            | Op::Beq => self.branch(bus),
            _ => match self.mode {
                Mode::Imp => {
                    self.read(bus, self.pc);
                    self.implied();
                    true
                }
                Mode::Acc => {
                    self.read(bus, self.pc);
                    self.a = self.modify(self.a);
                    true
                }
                Mode::Imm => {
                    let v = self.operand(bus);
                    self.exec_read(v);
                    true
                }
                _ => self.memory(bus),
            },
        }
    }

    /// `BRK`, IRQ, NMI and reset share one 7-cycle shape. The vector is chosen
    /// in cycle 4, so an NMI arriving before then hijacks a BRK or an IRQ.
    fn brk(&mut self, bus: &mut impl Bus) -> bool {
        self.skip_poll = true;
        match self.t {
            1 => {
                self.read(bus, self.pc);
                if self.entry == Entry::Brk {
                    self.pc = self.pc.wrapping_add(1);
                }
                false
            }
            2 => {
                self.brk_push(bus, (self.pc >> 8) as u8);
                false
            }
            3 => {
                self.brk_push(bus, self.pc as u8);
                false
            }
            4 => {
                let b = if self.entry == Entry::Brk { B } else { 0 };
                self.brk_push(bus, (self.p & !B) | U | b);
                self.addr = if self.entry == Entry::Reset {
                    RESET_VECTOR
                } else if self.nmi_edge {
                    self.nmi_edge = false;
                    NMI_VECTOR
                } else {
                    IRQ_VECTOR
                };
                false
            }
            5 => {
                self.data = self.read(bus, self.addr);
                self.p |= I;
                false
            }
            _ => {
                let hi = self.read(bus, self.addr.wrapping_add(1));
                self.pc = u16::from_le_bytes([self.data, hi]);
                true
            }
        }
    }

    /// Reset goes through the motions of the pushes as reads.
    fn brk_push(&mut self, bus: &mut impl Bus, value: u8) {
        if self.entry == Entry::Reset {
            self.read(bus, STACK | u16::from(self.s));
            self.s = self.s.wrapping_sub(1);
        } else {
            self.stack_push(bus, value);
        }
    }

    fn jsr(&mut self, bus: &mut impl Bus) -> bool {
        match self.t {
            1 => {
                self.data = self.operand(bus);
                false
            }
            2 => {
                self.read(bus, STACK | u16::from(self.s));
                false
            }
            3 => {
                self.stack_push(bus, (self.pc >> 8) as u8);
                false
            }
            4 => {
                self.stack_push(bus, self.pc as u8);
                false
            }
            _ => {
                // The high byte is fetched only after the pushes.
                let hi = self.read(bus, self.pc);
                self.pc = u16::from_le_bytes([self.data, hi]);
                true
            }
        }
    }

    fn rts(&mut self, bus: &mut impl Bus) -> bool {
        match self.t {
            1 => {
                self.read(bus, self.pc);
                false
            }
            2 => {
                self.read(bus, STACK | u16::from(self.s));
                self.s = self.s.wrapping_add(1);
                false
            }
            3 => {
                self.data = self.read(bus, STACK | u16::from(self.s));
                self.s = self.s.wrapping_add(1);
                false
            }
            4 => {
                let hi = self.read(bus, STACK | u16::from(self.s));
                self.pc = u16::from_le_bytes([self.data, hi]);
                false
            }
            _ => {
                self.read(bus, self.pc);
                self.pc = self.pc.wrapping_add(1);
                true
            }
        }
    }

    fn rti(&mut self, bus: &mut impl Bus) -> bool {
        match self.t {
            1 => {
                self.read(bus, self.pc);
                false
            }
            2 => {
                self.read(bus, STACK | u16::from(self.s));
                self.s = self.s.wrapping_add(1);
                false
            }
            3 => {
                let v = self.read(bus, STACK | u16::from(self.s));
                self.p = (v & !B) | U;
                self.s = self.s.wrapping_add(1);
                false
            }
            4 => {
                self.data = self.read(bus, STACK | u16::from(self.s));
                self.s = self.s.wrapping_add(1);
                false
            }
            _ => {
                let hi = self.read(bus, STACK | u16::from(self.s));
                self.pc = u16::from_le_bytes([self.data, hi]);
                true
            }
        }
    }

    fn jmp(&mut self, bus: &mut impl Bus) -> bool {
        if self.t == 1 {
            self.data = self.operand(bus);
            return false;
        }
        let hi = self.read(bus, self.pc);
        self.pc = u16::from_le_bytes([self.data, hi]);
        true
    }

    /// `JMP (ind)` with the NMOS page-wrap bug: the high byte comes from the
    /// start of the same page when the pointer ends in `$FF`.
    fn jmp_ind(&mut self, bus: &mut impl Bus) -> bool {
        match self.t {
            1 => {
                self.data = self.operand(bus);
                false
            }
            2 => {
                let hi = self.operand(bus);
                self.base = u16::from_le_bytes([self.data, hi]);
                false
            }
            3 => {
                self.data = self.read(bus, self.base);
                false
            }
            _ => {
                let hi_addr = (self.base & 0xff00) | (self.base.wrapping_add(1) & 0x00ff);
                let hi = self.read(bus, hi_addr);
                self.pc = u16::from_le_bytes([self.data, hi]);
                true
            }
        }
    }

    fn push_op(&mut self, bus: &mut impl Bus) -> bool {
        if self.t == 1 {
            self.read(bus, self.pc);
            return false;
        }
        let v = if self.op == Op::Pha { self.a } else { self.p | B | U };
        self.stack_push(bus, v);
        true
    }

    fn pull_op(&mut self, bus: &mut impl Bus) -> bool {
        match self.t {
            1 => {
                self.read(bus, self.pc);
                false
            }
            2 => {
                self.read(bus, STACK | u16::from(self.s));
                self.s = self.s.wrapping_add(1);
                false
            }
            _ => {
                let v = self.read(bus, STACK | u16::from(self.s));
                if self.op == Op::Pla {
                    self.a = v;
                    ops::set_nz(&mut self.p, v);
                } else {
                    self.p = (v & !B) | U;
                }
                true
            }
        }
    }

    /// The processor locks up: after the fetch it reads PC, then `$FFFF`,
    /// `$FFFE`, `$FFFE`, then `$FFFF` forever.
    fn jam(&mut self, bus: &mut impl Bus) -> bool {
        self.skip_poll = true;
        match self.t {
            1 => {
                self.read(bus, self.pc);
                self.jammed = true;
            }
            2 => {
                self.read(bus, 0xffff);
            }
            3 | 4 => {
                self.read(bus, 0xfffe);
            }
            _ => {
                self.read(bus, 0xffff);
            }
        }
        false
    }

    fn taken(&self) -> bool {
        match self.op {
            Op::Bpl => self.p & N == 0,
            Op::Bmi => self.p & N != 0,
            Op::Bvc => self.p & V == 0,
            Op::Bvs => self.p & V != 0,
            Op::Bcc => self.p & C == 0,
            Op::Bcs => self.p & C != 0,
            Op::Bne => self.p & Z == 0,
            _ => self.p & Z != 0,
        }
    }

    /// Branches poll before the operand fetch and, when a page is crossed,
    /// before the high-byte fix. A taken branch that stays on its page does
    /// not poll again, so it delays an interrupt by one instruction.
    fn branch(&mut self, bus: &mut impl Bus) -> bool {
        match self.t {
            1 => {
                self.data = self.operand(bus);
                if !self.taken() {
                    return true;
                }
                self.skip_poll = true;
                false
            }
            2 => {
                self.read(bus, self.pc);
                let target = self.pc.wrapping_add(self.data as i8 as u16);
                self.addr = target;
                self.pc = (self.pc & 0xff00) | (target & 0x00ff);
                self.pc == target
            }
            _ => {
                self.read(bus, self.pc);
                self.pc = self.addr;
                true
            }
        }
    }

    /// Instructions that reach an operand in memory: the address cycles, the
    /// page-cross cycle for indexed modes, then the access.
    fn memory(&mut self, bus: &mut impl Bus) -> bool {
        let (steps, indexed) = match self.mode {
            Mode::Zp => (1, false),
            Mode::Zpx | Mode::Zpy | Mode::Abs => (2, false),
            Mode::Izx => (4, false),
            Mode::Abx | Mode::Aby => (2, true),
            Mode::Izy => (3, true),
            Mode::Imp | Mode::Acc | Mode::Imm => unreachable!("handled in step"),
        };
        let t = self.t;
        if t <= steps {
            self.address(bus, t);
            return false;
        }
        let mut first = steps + 1;
        if indexed {
            if t == first {
                // The read before the high byte is fixed. When no page was
                // crossed it is already the right address, and a read
                // instruction finishes here.
                let unfixed = (self.base & 0xff00) | (self.addr & 0x00ff);
                let v = self.read(bus, unfixed);
                if self.op.kind() == Kind::Read && unfixed == self.addr {
                    self.exec_read(v);
                    return true;
                }
                return false;
            }
            first += 1;
        }
        self.access(bus, t - first)
    }

    fn address(&mut self, bus: &mut impl Bus, t: u8) {
        match (self.mode, t) {
            (Mode::Zp, _) => self.addr = u16::from(self.operand(bus)),
            (Mode::Zpx | Mode::Zpy | Mode::Izx | Mode::Izy, 1) => self.ptr = self.operand(bus),
            (Mode::Zpx, _) => {
                self.read(bus, u16::from(self.ptr));
                self.addr = u16::from(self.ptr.wrapping_add(self.x));
            }
            (Mode::Zpy, _) => {
                self.read(bus, u16::from(self.ptr));
                self.addr = u16::from(self.ptr.wrapping_add(self.y));
            }
            (Mode::Abs | Mode::Abx | Mode::Aby, 1) => self.data = self.operand(bus),
            (Mode::Abs, _) => {
                let hi = self.operand(bus);
                self.addr = u16::from_le_bytes([self.data, hi]);
            }
            (Mode::Abx | Mode::Aby, _) => {
                let hi = self.operand(bus);
                self.base = u16::from_le_bytes([self.data, hi]);
                let index = if self.mode == Mode::Abx { self.x } else { self.y };
                self.addr = self.base.wrapping_add(u16::from(index));
            }
            (Mode::Izx, 2) => {
                self.read(bus, u16::from(self.ptr));
                self.ptr = self.ptr.wrapping_add(self.x);
            }
            (Mode::Izx, 3) => self.data = self.read(bus, u16::from(self.ptr)),
            (Mode::Izx, _) => {
                let hi = self.read(bus, u16::from(self.ptr.wrapping_add(1)));
                self.addr = u16::from_le_bytes([self.data, hi]);
            }
            (Mode::Izy, 2) => self.data = self.read(bus, u16::from(self.ptr)),
            (Mode::Izy, _) => {
                let hi = self.read(bus, u16::from(self.ptr.wrapping_add(1)));
                self.base = u16::from_le_bytes([self.data, hi]);
                self.addr = self.base.wrapping_add(u16::from(self.y));
            }
            _ => unreachable!("{:?} has no address cycles", self.mode),
        }
    }

    /// The access at the effective address. `k` counts from 0.
    fn access(&mut self, bus: &mut impl Bus, k: u8) -> bool {
        match self.op.kind() {
            Kind::Read => {
                let v = self.read(bus, self.addr);
                self.exec_read(v);
                true
            }
            Kind::Write => {
                let (addr, v) = self.store();
                self.write(bus, addr, v);
                true
            }
            Kind::Rmw => match k {
                0 => {
                    self.data = self.read(bus, self.addr);
                    false
                }
                1 => {
                    // The NMOS part writes the unmodified value back first.
                    self.write(bus, self.addr, self.data);
                    self.data = self.modify(self.data);
                    false
                }
                _ => {
                    self.write(bus, self.addr, self.data);
                    true
                }
            },
            Kind::Other => unreachable!("{:?} does not access memory", self.op),
        }
    }

    fn exec_read(&mut self, v: u8) {
        let p = &mut self.p;
        match self.op {
            Op::Lda => {
                self.a = v;
                ops::set_nz(p, v);
            }
            Op::Ldx => {
                self.x = v;
                ops::set_nz(p, v);
            }
            Op::Ldy => {
                self.y = v;
                ops::set_nz(p, v);
            }
            Op::Lax => {
                self.a = v;
                self.x = v;
                ops::set_nz(p, v);
            }
            Op::Ora => {
                self.a |= v;
                ops::set_nz(p, self.a);
            }
            Op::And => {
                self.a &= v;
                ops::set_nz(p, self.a);
            }
            Op::Eor => {
                self.a ^= v;
                ops::set_nz(p, self.a);
            }
            Op::Adc => self.a = ops::adc(p, self.a, v),
            Op::Sbc => self.a = ops::sbc(p, self.a, v),
            Op::Cmp => ops::compare(p, self.a, v),
            Op::Cpx => ops::compare(p, self.x, v),
            Op::Cpy => ops::compare(p, self.y, v),
            Op::Bit => ops::bit(p, self.a, v),
            Op::Anc => self.a = ops::anc(p, self.a, v),
            Op::Alr => self.a = ops::alr(p, self.a, v),
            Op::Arr => self.a = ops::arr(p, self.a, v),
            Op::Sbx => self.x = ops::sbx(p, self.a, self.x, v),
            Op::Ane => self.a = ops::ane(p, self.a, self.x, v),
            Op::Lxa => {
                let r = ops::lxa(p, self.a, v);
                self.a = r;
                self.x = r;
            }
            Op::Las => {
                let r = v & self.s;
                self.a = r;
                self.x = r;
                self.s = r;
                ops::set_nz(p, r);
            }
            Op::Nop => {}
            _ => unreachable!("{:?} does not read", self.op),
        }
    }

    fn modify(&mut self, v: u8) -> u8 {
        let p = &mut self.p;
        match self.op {
            Op::Asl => ops::asl(p, v),
            Op::Lsr => ops::lsr(p, v),
            Op::Rol => ops::rol(p, v),
            Op::Ror => ops::ror(p, v),
            Op::Inc => {
                let r = v.wrapping_add(1);
                ops::set_nz(p, r);
                r
            }
            Op::Dec => {
                let r = v.wrapping_sub(1);
                ops::set_nz(p, r);
                r
            }
            Op::Slo => {
                let r = ops::asl(p, v);
                self.a |= r;
                ops::set_nz(p, self.a);
                r
            }
            Op::Rla => {
                let r = ops::rol(p, v);
                self.a &= r;
                ops::set_nz(p, self.a);
                r
            }
            Op::Sre => {
                let r = ops::lsr(p, v);
                self.a ^= r;
                ops::set_nz(p, self.a);
                r
            }
            Op::Rra => {
                let r = ops::ror(p, v);
                self.a = ops::adc(p, self.a, r);
                r
            }
            Op::Dcp => {
                let r = v.wrapping_sub(1);
                ops::compare(p, self.a, r);
                r
            }
            Op::Isc => {
                let r = v.wrapping_add(1);
                self.a = ops::sbc(p, self.a, r);
                r
            }
            _ => unreachable!("{:?} does not modify", self.op),
        }
    }

    /// The address and value of a store. `SHA SHX SHY TAS` AND the value with
    /// the base address's high byte + 1, and on a page crossing that value
    /// also replaces the high byte of the address.
    fn store(&mut self) -> (u16, u8) {
        match self.op {
            Op::Sta => (self.addr, self.a),
            Op::Stx => (self.addr, self.x),
            Op::Sty => (self.addr, self.y),
            Op::Sax => (self.addr, self.a & self.x),
            Op::Sha => self.unstable_store(self.a & self.x),
            Op::Shx => self.unstable_store(self.x),
            Op::Shy => self.unstable_store(self.y),
            Op::Tas => {
                self.s = self.a & self.x;
                self.unstable_store(self.s)
            }
            _ => unreachable!("{:?} does not store", self.op),
        }
    }

    fn unstable_store(&self, value: u8) -> (u16, u8) {
        let v = value & ((self.base >> 8) as u8).wrapping_add(1);
        if self.addr & 0xff00 == self.base & 0xff00 {
            (self.addr, v)
        } else {
            ((u16::from(v) << 8) | (self.addr & 0x00ff), v)
        }
    }

    fn implied(&mut self) {
        let p = &mut self.p;
        match self.op {
            Op::Tax => {
                self.x = self.a;
                ops::set_nz(p, self.x);
            }
            Op::Tay => {
                self.y = self.a;
                ops::set_nz(p, self.y);
            }
            Op::Txa => {
                self.a = self.x;
                ops::set_nz(p, self.a);
            }
            Op::Tya => {
                self.a = self.y;
                ops::set_nz(p, self.a);
            }
            Op::Tsx => {
                self.x = self.s;
                ops::set_nz(p, self.x);
            }
            Op::Txs => self.s = self.x,
            Op::Inx => {
                self.x = self.x.wrapping_add(1);
                ops::set_nz(p, self.x);
            }
            Op::Iny => {
                self.y = self.y.wrapping_add(1);
                ops::set_nz(p, self.y);
            }
            Op::Dex => {
                self.x = self.x.wrapping_sub(1);
                ops::set_nz(p, self.x);
            }
            Op::Dey => {
                self.y = self.y.wrapping_sub(1);
                ops::set_nz(p, self.y);
            }
            Op::Clc => *p &= !C,
            Op::Sec => *p |= C,
            Op::Cli => *p &= !I,
            Op::Sei => *p |= I,
            Op::Clv => *p &= !V,
            Op::Cld => *p &= !D,
            Op::Sed => *p |= D,
            Op::Nop => {}
            _ => unreachable!("{:?} is not implied", self.op),
        }
    }
}
```

```rust
#![allow(dead_code)]

use mos6510::{Bus, Cpu, Model};

pub struct Ram {
    pub mem: Vec<u8>,
    pub writes: Vec<(u16, u8)>,
}

impl Ram {
    pub fn new() -> Self {
        Self {
            mem: vec![0; 0x1_0000],
            writes: Vec::new(),
        }
    }

    pub fn load(&mut self, at: u16, bytes: &[u8]) {
        let at = usize::from(at);
        self.mem[at..at + bytes.len()].copy_from_slice(bytes);
    }

    pub fn vector(&mut self, at: u16, target: u16) {
        self.load(at, &target.to_le_bytes());
    }
}

impl Bus for Ram {
    fn read(&mut self, addr: u16) -> u8 {
        self.mem[usize::from(addr)]
    }

    fn write(&mut self, addr: u16, value: u8) {
        self.mem[usize::from(addr)] = value;
        self.writes.push((addr, value));
    }
}

pub const IRQ_HANDLER: u16 = 0x0300;
pub const NMI_HANDLER: u16 = 0x0400;

/// A 6502 about to run `program` at `$0200`, with S = `$FF`, every flag clear
/// (I included), and IRQ/NMI handlers made of NOPs.
pub fn setup(program: &[u8]) -> (Cpu, Ram) {
    let mut ram = Ram::new();
    ram.load(0x0200, program);
    ram.load(IRQ_HANDLER, &[0xea; 16]);
    ram.load(NMI_HANDLER, &[0xea; 16]);
    ram.vector(0xfffe, IRQ_HANDLER);
    ram.vector(0xfffa, NMI_HANDLER);
    ram.vector(0xfffc, 0x0200);
    let mut cpu = Cpu::new(Model::Mos6502);
    cpu.s = 0xff;
    cpu.p = 0x20;
    cpu.jump(0x0200);
    (cpu, ram)
}

pub fn ticks(cpu: &mut Cpu, ram: &mut Ram, n: usize) {
    for _ in 0..n {
        cpu.tick(ram);
    }
}

/// The return address of an interrupt taken with S = `$FF`.
pub fn pushed_return(ram: &Ram) -> u16 {
    u16::from_le_bytes([ram.mem[0x01fe], ram.mem[0x01ff]])
}

/// The status byte of an interrupt taken with S = `$FF`.
pub fn pushed_status(ram: &Ram) -> u8 {
    ram.mem[0x01fd]
}
```

```rust
//! Klaus Dormann's 6502 functional test. Every failure is a branch or jump to
//! itself, and so is success, at `$3469` in the published binary; any other
//! trap address names the failing check in `6502_functional_test.lst`.
//!
//! The binary is GPL-3.0 and not in the repository. Fetch it with
//! `sh scripts/fetch-klaus.sh` and run with `KLAUS_DIR=target/test-data/klaus`.

use mos6510::{Bus, Cpu, Model};
use std::path::PathBuf;

const SUCCESS: u16 = 0x3469;

struct Flat(Vec<u8>);

impl Bus for Flat {
    fn read(&mut self, addr: u16) -> u8 {
        self.0[usize::from(addr)]
    }

    fn write(&mut self, addr: u16, value: u8) {
        self.0[usize::from(addr)] = value;
    }
}

#[test]
fn klaus_dormann_functional_test() {
    let Some(dir) = std::env::var_os("KLAUS_DIR").map(PathBuf::from) else {
        eprintln!("skipped: KLAUS_DIR is not set (run scripts/fetch-klaus.sh)");
        return;
    };
    let path = dir.join("6502_functional_test.bin");
    let Ok(image) = std::fs::read(&path) else {
        eprintln!("skipped: {} not found", path.display());
        return;
    };
    assert_eq!(image.len(), 0x1_0000, "the image must be a full 64 KiB");

    let mut bus = Flat(image);
    let mut cpu = Cpu::new(Model::Mos6502);
    cpu.jump(0x0400);
    let mut last = None;
    let mut instructions = 0u64;
    loop {
        cpu.tick(&mut bus);
        if cpu.at_instruction_boundary() {
            if last == Some(cpu.pc) {
                break;
            }
            last = Some(cpu.pc);
            instructions += 1;
            assert!(instructions < 100_000_000, "runaway at ${:04X}", cpu.pc);
        }
    }
    assert_eq!(
        cpu.pc, SUCCESS,
        "trapped at ${:04X} after {instructions} instructions; look it up in 6502_functional_test.lst",
        cpu.pc
    );
}
```

```rust
        if self.trace.enabled {
            let pc = cpu.pc;
            let m = self.machine.borrow();
            self.trace.note(pc, &m.ram);
        }
        let underflow = self.machine.borrow().cia.borrow_mut().tick();
        if self.frame_clock {
            // The tune brought no handler, so the harness is the player. It
            // cannot wait on the processor's interrupt flag, because a tune
            // initialised with interrupts masked never clears it — a real
            // machine reaches the player through the Kernal's own chain, which
            // runs with interrupts enabled by then. Enter the play stub
            // directly, at an instruction boundary, with the processor idle.
            if self.machine.borrow().cia.borrow().started {
                self.frame_due |= underflow;
            } else {
                self.frame_cycles += 1;
                self.frame_due |= self.frame_cycles >= self.frame_period;
            }
            // A tick that arrives while an instruction is still running, or
            // while a previous play call has not returned, is held rather than
            // dropped: losing it would silently slow every tune whose play
            // routine happens to straddle the tick.
            if self.frame_due && cpu.at_instruction_boundary() && cpu.pc == self.stubs.halt {
                self.frame_due = false;
                self.frame_cycles = 0;
                cpu.jump(self.stubs.play);
                self.frames += 1;
            }

            // The tune owns the interrupt vector, so it is driven by its CIA the
            // same way it is on a real machine: the CIA's level-triggered line
            // is wired to the processor's, which samples it where the hardware
            // does.
            cpu.set_irq(self.machine.borrow().cia.borrow().line());

        // Counted at the boundary, so the summary reports interrupts the
        // processor actually took rather than ones merely requested.
        if cpu.interrupt_pending() {
            self.irqs += 1;
        }
        cpu.tick(&mut self.bus);
        self.machine
```
